# Ale Abbey - التعريب الكامل

تعريب كامل لـAle Abbey على Steam بالعربية الفصحى: 2,978 سطرًا تشمل القوائم والإعدادات، ودليل اللعبة، ومهام الأسقف، والأحداث والقرارات، والوصفات وطُرُز الجعة والمكوّنات، والأسواق والطلبيات، والفِرمِنتيّين وسماتهم، والتلميحات ورسائل النظام. تُضاف العربية لغةً جديدة في إعدادات اللعبة، ولا تتغير اللغات الأخرى.

**إصدار تجريبي (1.0.0-beta):** أرسل صورة لأي نص غير مترجم أو مقصوص أو خارج مكانه في [Issues](../../issues).

## التحميل

من صفحة [الإصدارات](../../releases/latest) حمّل أحد الملفين:

- `Ale Abbey - Arabic v1.0.0-beta.exe`: المثبّت، لا يحتاج إلى أي شيء آخر.
- `Ale Abbey - Arabic v1.0.0-beta (Manual).zip`: نفس الملفات للتثبيت اليدوي أو لـSteam Deck، والخطوات في الملف `Arabic - INSTALL_MANUAL.txt` داخله.

## التثبيت

1. أغلق اللعبة.
2. شغّل المثبّت واضغط «تثبيت اللغة العربية». يجد المثبّت اللعبة تلقائيًا من مكتبة Steam، وإن لم يجدها اختر مجلدها بنفسك.
3. شغّل اللعبة. أول تشغيل بعد التثبيت يستغرق دقيقة أو دقيقتين ويحتاج اتصالًا بالإنترنت مرة واحدة فقط، وقد لا تظهر نافذة اللعبة خلالها، فلا توقفها من Steam.
4. من الإعدادات ← اللغة اختر «العربية».

إن ظهرت رسالة "Windows protected your PC" اضغط More info ثم Run anyway.

للإزالة: شغّل المثبّت واضغط «إزالة اللغة العربية»، فتعود اللعبة إلى الإنجليزية.

## ما يميّز هذا التعريب

- **العربية لغة مستقلة:** تظهر «العربية» في قائمة اللغات بجانب لغات اللعبة، ولا يُستبدل أي ملف من ملفات اللعبة.
- **نص عربي سليم داخل اللعبة:** حروف متصلة بخط SST Arabic، والنصوص من اليمين إلى اليسار، والأرقام في ترتيبها الصحيح.
- **مخاطبة رئيس الدير أو رئيسة الدير بصيغة الاحترام:** «سموّكم».
- **مثبّت بضغطة واحدة** وزر إزالة يعيد اللعبة كما كانت.

## تنبيه

- صُمّم لإصدار Steam رقم 21021822 (Ver. 1.1.20251202.01). بعد أي تحديث للعبة قد تحتاج إلى نسخة جديدة من التعريب.
- إن بدا نص ما صغيرًا جدًا أو بترتيب غريب، يمكن إيقاف التصغير التلقائي (`ShrinkToFit`) أو قلب الصفوف (`ReverseRows`) من الملف `BepInEx\config\faisalkindi.aleabbey.arabic.cfg` بجعل القيمة `false`.

**English:** A full Modern Standard Arabic translation of Ale Abbey (Steam): 2,978 lines covering menus, settings, the game manual, Bishop tasks, events, recipes, ale styles, markets, orders, monk traits, tooltips and system messages. Arabic is added as its own language in Settings > Language; no game file is replaced. Download the installer or the manual zip from [Releases](../../releases/latest), close the game, install, then pick «العربية» in Settings > Language. Built for Steam build 21021822 (Ver. 1.1.20251202.01). Steam Deck / Linux: use the manual zip and set the launch options to `WINEDLLOVERRIDES="winhttp=n,b" %command%`.
